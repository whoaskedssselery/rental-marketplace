# Onest

Static Regular (400), Medium (500), and SemiBold (600) TTF files from the official Onest 2.001
release: https://github.com/simpals/onest/releases/tag/2.001

The font files are unmodified and bundled under the SIL Open Font License 1.1;
see OFL.txt in this directory. The application registers them with JavaFX at
startup. No system font installation or runtime network request is required.
